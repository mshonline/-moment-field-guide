# Changelog

One entry per version, newest first. The app's What's New view reads this file. Keep the table format: two columns, what changed and where it stands now.

## Version 3, 28 August 2026

Folds in the 28 August session.

| What changed | Where it stands now |
| --- | --- |
| Auto Connect is now off | This solved the mystery of shots landing on the SD card when you had chosen the photo library. Sliding the phone into the grip was switching the storage location on its own. Nothing you did wrong. |
| ISO starts at 400 | Saved into both Natural and ProRAW. Easier to bring ISO down than to discover a shutter too slow to hold, especially with the ND on. |
| File Name Format is Default, not Date | Tested side by side on both phones. Default gives the clean IMG numbers. Video ignores the setting entirely and always uses the long timecode name. |
| A copyright step joins the workflow | Photo Mechanic writes the IPTC copyright into the exported files, then a Finder rename tags them. This is now the last thing that happens before anything goes out. Part 4 has the sequence. |
| Autofocus: let the camera choose | Tried at Hyannis and everything came back sharp. The lens is wide with deep depth of field, so tapping the white box mostly costs you the moment. |
| Drive setup checks out | Sessions Primary, Sessions Backup, and the Raw Captures Archive are all set up correctly. |

## Version 2, 13 August 2026

Restructured the media workflow around the Capture One session. Earlier versions predate this changelog.

| What changed | Where it stands now |
| --- | --- |
| Everything flows through the session | One session folder per shoot holds camera roll and SD card captures, edits, and outputs. Three drives, renamed: Sessions Primary, Sessions Backup from Primary, Raw Captures Archive Primary. |
| Capture One renames video | Tested live with a 3 GB clip. Batch rename covers photo and video together, so nothing has to be renamed in Finder. |
| Two copies before deleting | The session is copied to the backup drive before anything is deleted from Photos. |
